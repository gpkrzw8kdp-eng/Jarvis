# J.A.R.V.I.S. HUD

Ein animiertes Iron-Man-Style Desktop-HUD als einzelne HTML-Datei (`index.html`).

- Arc-Reaktor mit rotierenden Ringen und rotem Scanner-Bogen (Canvas)
- Live: Uhr, Datum, Monatsleiste, Sonnenauf-/untergang (Berlin), Browser-Speicher, Akku (falls verfügbar)
- Simuliert: CPU, RAM, Netzwerk; Wetter sind Beispieldaten
- Jarvis-Konsole: lokale Befehle (`hilfe`, `status`, `zeit`, `datum`, `alarm`, `normal`, `vollbild`, `leeren`);
  als claude.ai-Artifact antwortet Jarvis frei über Claude und kann den Alarmmodus selbst schalten
- Optionale Sprachausgabe („Stimme“)

Lokal starten: `index.html` im Browser öffnen.
